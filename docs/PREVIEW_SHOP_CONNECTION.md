## Что пока не подключено

В работающем preview смонтирован только `/run/secrets/storefront_database_url`.
SHOP-секрета и SHOP_DATABASE_URL_FILE нет. Контейнер работает от UID 1000, исходные
файлы принадлежат UID 1001 и специально ему недоступны. Не менять права исходных
секретов на общедоступные и не подменять действующий каталоговый DATABASE_URL_FILE.

Подготовленные файлы:

- `deploy/dev/compose.shop.pending.yaml` — только предлагаемое дополнение Compose;
- `deploy/dev/load-shop-secret.cjs` — Node preload, разрешающий исключительно
  storefront_preview_shop_app в elektrikamarket_preview_shop/schema=shop;
- `deploy/dev/secret-loader.test.cjs` — проверки разделения и отказа ошибочного target.

Дополнение сохраняет базовый catalog secret и добавляет SHOP_DATABASE_URL_FILE.
Preload устанавливает только серверный SHOP_DATABASE_URL перед существующим
start.cjs. Каталоговый startup, reader, торговые правила и код Андроника не меняются.
Сам клиент БД покупателей должен добавить Андроник отдельно.

## Следующее применение — только после согласования

1. Получить и отрепетировать миграции Андроника локально; проверить ORM/клиент SHOP.
2. Сделать backup отдельной shop-БД существующим подготовленным backup-shop.sh.
3. После разрешения применить миграции мигратором, затем explicit table grants
   существующим grant-approved-tables.sql. Проверить CRUD и отрицательные права.
4. Администратору создать **новую** root-контролируемую копию app-секрета
   `/etc/elektrikamarket-preview/shop_database_url`, читаемую UID 1000 (0400).
   Исходные секреты не менять. Миграционный секрет не копировать в preview.
5. Установить публичный preload в root-контролируемый каталог и после обзора
   объединить base Compose с pending-дополнением в действующий фиксированный
   `/etc/elektrikamarket-preview/compose.yaml`. Сейчас deployer читает только этот
   файл; отдельно лежащий pending override сам по себе не применяется.
6. Проверить config --quiet. Отдельно согласовать пересоздание **только preview**.
   Изменение mount/environment/command требует нового контейнера, обычного restart
   недостаточно. Будет краткий перерыв preview; test/PostgreSQL/Caddy не затрагиваются.
7. Проверить HTTPS/Auth, каталог, SHOP CRUD, запреты DDL и каталоговой записи.
   Откат подключения — прежний Compose и прежний preview-образ; shop-БД не удалять
   и не откатывать поверх существующей без отдельного решения.

В рамках текущей задачи эти действия не применялись. Новые VPS-файлы, mounts,
grants, миграции, перезапуски и изменения deployer не выполнялись.

## Что передать Андронику

Достаточны имя переменной SHOP_DATABASE_URL, схема shop, назначение ролей, отдельная
локальная среда и эти инструкции. Внутри VPS hostname — postgres, порт 5432;
он доступен только во внутренней Docker-сети, не с домашнего ПК.

VPS-пароли и SSH-ключ Андронику не нужны. Приложение получит app-секрет внутренним
mount после согласования владельца. Миграции на VPS выполняет владелец/оператор,
миграционный секрет не передаётся другу/Actions. Для локальной разработки каждый
ПК получает собственные случайные реквизиты через dev.cjs setup; они хранятся в
deploy/dev/.local и используются скриптом запуска без ручного копирования URL.
