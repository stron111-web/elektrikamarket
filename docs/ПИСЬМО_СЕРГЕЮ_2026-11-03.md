## Что сделано

На оформлении, способ «Пункт выдачи»:

- Город набирается с подсказками, список городов сужается по мере букв.
- После выбора города показываются пункты СДЭК этого города. В Тольятти в открытом списке 33.
- После запятой можно дописать улицу, список сузится до этой улицы.
- В строке списка только улица, дом и часы работы. Индекс, страна, область и город в списке не пишутся. Шрифт списка мелкий.
- Нажатие на строку ставит полный адрес в поле «Пункт выдачи». Строка при этом зелёная.
- Кнопка «Выбрать на карте» открывает карту города с точками. Улицы на ней видны. Точку можно нажать и на карте, и в списке.

Цена доставки по нашему договору пока не считается.

Запоминание выбранного пункта в кабинете на превью само не включится. Для этого к базе магазина, не к базе каталога, нужно применить `deploy/dev/migrations/005_shop_delivery.sql`. Выкладка сайта этот файл не запускает.

## Ключи

Сейчас это работает не нашими ключами. Наши как раз не подключены, хотя должны были.

На экране реально используется вот что:

1. Учебная пара СДЭК. Идентификатор и пароль, которые публикует сам СДЭК для пробы. Ими ищется город и берутся координаты. Это не ключ кабинета «Тольяттинская Кабельная».
2. Список пунктов СДЭК. Открытый перечень, без ключа.
3. Картинка карты. Улицы рисует чужая карта Esri, без ключа. Это не Яндекс. Внизу карты чужой значок, для магазина он не годится.

Наши ключи есть, но этот экран их не использует:

4. Пара кабинета СДЭК от 10.05.2026: идентификатор и защитный пароль. Нужна для цены доставки. Страница её не приняла. Новый ключ создавать не нужно.
5. Ключ JavaScript API Яндекса, ключ №1. Нужен, чтобы карта была яндексовой. На превью он не подставлен.
6. Ключ Геокодера Яндекса, ключ №2. Оформление заказа его пока не вызывает.

Проверь, пожалуйста, как это открывается у тебя на превью.
