# Яндекс Карта при переносе на боевой сайт

Превью https://preview.elektro-24.ru уже открывает Яндекс Карту на выборе пункта СДЭК. Боевой магазин https://elektrikamarket.ru от этой ветки сам не обновляется. Когда готовые доработки переносят на постоянный сайт, карту заново не программируют. Две вещи код с собой не уносит, и без них рамка на боевом снова будет пустой.

## Уже едет вместе с кодом

- Кнопка «Выбрать на карте» и точки пунктов.
- Просьба к Яндексу «дай карту» уходит вместе с именем того сайта, который сейчас открыт. На превью браузер называет `preview.elektro-24.ru`. На боевом он сам назовёт `elektrikamarket.ru`. Имя превью в страницу навсегда не вписано. Без этого имени Яндекс отвечает отказом, даже если ключ верный.
- Запись ключа в страницу во время сборки, если сборке этот ключ передали. В Git ключ не хранится: там пустая заготовка.
- Чужая карта больше не подставляется.

## Что сделать руками один раз

1. Кабинет Яндекса, ключ JavaScript API. В ограничении по HTTP Referer рядом с `preview.elektro-24.ru` добавить `elektrikamarket.ru`. Строку превью не стирать. Если покупатели открывают и `www.elektrikamarket.ru`, добавить и его. Нажать «Сохранить». Новый ключ не создавать. Пока панель открыта и видны «Отмена» и «Сохранить», запись ещё не сохранена.
2. Сборка именно боевого сайта должна получить тот же ключ до сборки страницы и вписать его в страницу тем же способом, что превью. Секрет превью `PREVIEW_YANDEX_JS_API_KEY` боевой сайт сам не читает. Ключ не писать в Git и не класть в закрытый Compose: страница собирается раньше и пустое окружение контейнера ключ не заменяет.

Стенд https://test.elektro-24.ru — отдельный адрес. Карта там откроется только если и его имя есть в том же списке кабинета, и его сборка получила ключ.

## Как понять, что получилось

На боевом: корзина, оформление, пункт выдачи, город, «Выбрать на карте». В углу карты подпись «Яндекс Карты», точка выбирает пункт. Заказ для проверки не отправлять.

Пустая рамка и фраза «на этом запуске не подключена» — ключ не попал в сборку этого сайта. Фраза «Яндекс Карта не открылась» — ключ на странице есть, а Яндекс не пустил этот адрес: список в кабинете не сохранён или браузер не отправил имя сайта.
