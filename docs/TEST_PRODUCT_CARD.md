# Карточка товара Test (Issue #8)

Основа `1d93cd2`, Next 16.4.6. Чтение `product_features` только по открытому
productId внутри существующей REPEATABLE READ READ ONLY транзакции. Выбираются
featureCode/featureName/featureValue/featureUom с уже выданными правами. Запрос
не ограничивает число строк, использует существующий индекс productId/identityKey.
Никаких миграций, импортов, ACL или пересчёта коммерческих предложений.

Первые 10 ETIM-свойств раскрыты сразу, оставшиеся полностью присутствуют в HTML
в доступном с клавиатуры details. Пустые значения и технические JSON не выводятся.
Группировка только по точной тройке code/name/uom, уникальные значения сохраняются;
границы с/по и разные единицы не конвертируются. Совпавшие название и значение
общего поля не дублируются с ETIM. Нет предположений о незаполненных данных.

Цена, UOM, содержимое единицы и кратность читаются из принятого снимка источника
выбранной цены. Остатки отдельно по складам. NMP — целая упаковка, без деления цены
или умножения остатка на содержимое. Нет доступного оффера — честное сообщение.
Корзины и кнопки покупки нет: корзина/оформление — следующий отдельный этап.

Фото/документы — существующие http(s) ссылки, внешние ссылки noopener noreferrer.
Галерея с клавиатурными кнопками, активным кадром/счётчиком, открытием оригинала,
честным placeholder при ошибке источника. Название и тип документа, расширение
по реальному имени URL; файл не генерируется и его формат не угадывается без расширения.

Проверки: 4 целевых теста нормализации/идентичности/полноты/дедупликации общих полей,
14 существующих коротких тестов поиска/ETIM/фильтров, TypeScript и production build.
Проверка 6 реальных карточек с SQL-эталоном, HTTPS и мобильными 320/360/390px.
