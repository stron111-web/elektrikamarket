# Локальная витрина

Node.js 24. Из корня репозитория:

```powershell
cd web
npm ci
npm run dev
```

Адрес: http://localhost:3000/catalog. Сервер слушает только 127.0.0.1.

Проверка и запуск собранной версии:

```powershell
npm run build
npm start
```

Проверка 20 реальных товаров и основных страниц при запущенном сайте: `node tests/smoke.cjs`.

DATABASE_URL читается сервером из окружения либо существующего ../.env. Не создавайте NEXT_PUBLIC_DATABASE_URL. Все запросы идут в READ ONLY транзакциях; подключение устанавливает default_transaction_read_only=on. Цены, доступные остатки и упаковки читаются из активного коммерческого снимка. Импортёр использует прежние канонические PRICAT-функции при построении снимка.

Изображения загружаются браузером по исходным HTTP(S) ссылкам без серверного прокси и массового скачивания. Неработающие ссылки заменяются заглушкой. Упаковка берётся из коммерческого источника выбранной цены. NMP отображается только за целую упаковку.

Каталог и поиск показывают исключительно товары активного коммерческого снимка. Переключатель «Все товары / В наличии» удалён; availability=all, диагностические параметры и прежний STOREFRONT_DIAGNOSTICS не дают обхода. Счётчик и пагинация читают одну генерацию в REPEATABLE READ READ ONLY транзакции. Поиск — буквальный регистронезависимый фрагмент name/supplierCode/vendorNumber через ILIKE; pg_trgm GIN-индексы ускоряют эти поля без дублирования PRODAT в снимке.

Полный изолированный сценарий — node scripts/storefront/check-local.cjs <private-database.dump> [image] из корня проекта; он создаёт новый PostgreSQL и не подключается к сохраняемым БД. Проверяются эквивалентность, права, поиск/фильтры/пагинация и HTTP. web/tests/smoke.cjs также проверяет игнорирование старых параметров и отсутствие переключателя. Описание схемы, импорта, измерений и ограничений — docs/ASSORTMENT_SNAPSHOT.md.

Это локальный MVP без корзины, заказов и ETIM. Перед публикацией потребуется отдельная проверка эксплуатации и доступности внешних ресурсов. Импортёры должны оставаться рядом с web; это не автономная сборка.
