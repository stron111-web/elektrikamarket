# Локальная витрина

Node.js 24. Из корня репозитория:

```powershell
cd web
npm ci
npm run dev
```

Адрес: http://localhost:3000/catalog. Сервер слушает только 127.0.0.1.

Проверка и запуск собранной версии:

```powershell
npm run build
npm start
```

Проверка 20 реальных товаров и основных страниц при запущенном сайте: `node tests/smoke.cjs`.

DATABASE_URL читается сервером из окружения либо существующего ../.env. Не создавайте NEXT_PUBLIC_DATABASE_URL. Все запросы идут в READ ONLY транзакциях, подключение также устанавливает default_transaction_read_only=on. Схема и импортёры не изменяются. Цены и доступность получаются существующими функциями PRICAT только для 24 товаров страницы либо одного товара карточки. В режиме «Все товары» каталог показывает и недоступные товары с соответствующей пометкой.

Изображения загружаются браузером по исходным HTTP(S) ссылкам без серверного прокси и массового скачивания. Неработающие ссылки заменяются заглушкой. Упаковка берётся из коммерческого источника выбранной цены. NMP отображается только за целую упаковку.

Каталог по умолчанию показывает «В наличии»; `?availability=all` открывает полный каталог. Поиск, категории, бренд и пагинация сохраняют режим. Точная доступность вычисляется в PostgreSQL до пагинации из SQL существующего `readAvailableStocks`: модуль `lib/availability.cjs` компонует запрос, не копируя торговые правила. Совпадающие ID материализуются только внутри одного read-only запроса для точного счётчика и страницы; в приложение возвращаются максимум 24 товара. Нет постоянных таблиц, миграций или кеша доступности. Полный подсчёт доступности на текущей локальной БД занимает примерно 5 секунд; режим всех товаров — около 0,1 секунды.

`node tests/availability.cjs` проверяет эквивалентность SQL фильтра прямому вызову импортёра на реальных товарах, включая карантин, несовместимую UOM и пустую выборку. `node tests/smoke.cjs` проверяет оба режима и HTTP-страницы. Отсутствие цены при отсутствии коммерческих данных и успешных PRICAT-диагностик отображается как «Цена отсутствует»; при наличии данных, отклонённых торговой логикой, остаётся «Цена не подтверждена».

Это локальный MVP без корзины, заказов и ETIM. Перед публикацией потребуется отдельная проверка эксплуатации и доступности внешних ресурсов. Импортёры должны оставаться рядом с web; это не автономная сборка.
