# Три демоверсии каталога

Отдельное read-only приложение. База оформления — реально развёрнутый
`preview/friend@3fca01e2`. Общий CSS Preview импортируется без изменений;
логотип, Photo, DepartmentIcon и форматирование скопированы из того же среза.
Построение каталога, меню и страниц реализовано заново в `demos/catalogs`.
Рабочие `web/app/catalog`, Header, корзина, кабинет и админка не меняются
и не входят в образ демоприложения.

Маршруты:

- `/demo/catalogs` — выбор концепции;
- `/demo/catalog-v1` — многоуровневое меню и переход сразу к товарам;
- `/demo/catalog-v2` — последовательные страницы категорий;
- `/demo/catalog-v3` — быстрый переход, обзор разделов и контекстная навигация.

Переключатель сохраняет категорию, поисковую строку, страницу и режим просмотра
товаров. Иерархия и названия берутся только из PostgreSQL. Сортировка разделов
для удобства демонстрации не изменяет исходные parentId. Никаких искусственных
категорий в рабочие данные не добавляется. Пустые разделы отмечены нулевым числом
предложений, а не заполняются придуманными товарами.

`lib/data.ts` вызывает существующий `readCatalog`, поиск и `attachSnapshotOffers`.
Категории, их счётчики и товары читаются в одной REPEATABLE READ READ ONLY
транзакции. Товары ограничены активным снимком, 24 позиции на страницу.
Закупочные цены не выбираются и не сериализуются в HTML/React payload.
Читается существующая роль `storefront_test_ro`, без выдачи новых grants,
миграций или подключения writer-секрета. Импорты и rebuild не вызываются.

Фильтры — интерактивный макет с явной пометкой: checkbox, диапазоны,
сворачиваемые группы, применение/сброс и мобильный dialog. Применение сообщает,
что выдача не изменилась. Бренды берутся с реальной текущей страницы; остальные
значения — явно демонстрационные варианты, не утверждение о заполненности ETIM.
Сортировка отключена и помечена «демо». Корзины и оформления заказов нет.

## Проверки разработки

В `demos/catalogs`:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run typecheck
npm run build
npm audit --omit=dev
```

Закреплён исправленный Next.js 16.4.5. Исходный lock Preview содержал 16.4.0;
сборка остановилась на security audit. Обновлены только зависимости демо.
Основание: [официальное исправление Next.js](https://nextjs.org/blog/nextjs-security-update-october-14-2026).
Это не обновление зависимостей или развёртываний рабочих сайтов.

## Изолированное размещение на VPS

Сборка — `deploy/catalog-demos/Dockerfile`, собственный строгий allowlist контекста.
Приложение не содержит рабочих shop write-routes, сессий покупателей или платежей.
Новые контейнеры помечены `elektrikamarket.scope=catalog-demos`; их имена:
`elektrikamarket-catalog-demos-web` и `elektrikamarket-catalog-demos-gateway`.

Приложение слушает только Docker-сети и loopback VPS `127.0.0.1:18081`.
Отдельный gateway предоставляет `https://test.elektro-24.ru:8443/demo/catalogs`.
Существующие DNS, маршруты 80/443, Caddy и контейнеры Test/Preview не меняются.
Gateway читает существующий сертификат только домена Test и его basic_auth
через read-only mounts; ключи и пароли не копируются в Git или образ.
Все страницы, static и API защищены Basic Auth. Допускаются только GET/HEAD;
POST и другие методы отклоняются 405 после аутентификации. Добавлен noindex.

`deploy/catalog-demos/install.py` — первый установщик только нового стенда:
проверяет свободные порты, отсутствие второго демо, SELECT-права роли,
фиксирует ID/images/StartedAt существующих четырёх контейнеров и crontab,
после запуска проверяет их неизменность. Никаких действий с PostgreSQL-контейнером
и расписанием импортов. Новые контейнеры имеют лимиты CPU/RAM и read-only rootfs.

Сертификат читает отдельный gateway; после обновления сертификата рабочим Caddy
нужно перезапустить **только demo-gateway**, чтобы перечитать TLS-файлы.
Отключение демо — остановить два контейнера с меткой catalog-demos.
Не применять compose down или prune к рабочим проектам. Данные магазина не
требуют отката: демо не имеет прав записи. Журналы и результаты проверки хранятся
на VPS в `/home/shopadmin/elektrikamarket-catalog-demos/`, вне Git.
